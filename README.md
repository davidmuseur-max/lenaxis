# LENAXIS — site finalisé

Site statique, 10 modules natifs, fonctions transversales ALERTS et AT, page LÉNA / ASK LENA. Contenus issus des fiches modules Dropbox, sans garanties de résultats chiffrés.

Les capsules locales sont extraites de Lenaxis FR.mp4. Les passages spécifiques disponibles concernent la cartographie WATCH, AUDIT, ALERTS et CRISIS. Les autres pages présentent un extrait transversal explicitement identifié.

ASK LENA public : présentation et demande d’accès ; pas de chat public ni de paiement activé dans ce site vitrine. Les accès existants renvoient à LENAXIS en production.

Logos spécifiques STATS, AT et LÉNA non retrouvés : identité principale LENAXIS conservée.

Validation : liens et fichiers contrôlés, version mobile avec menu et accès à toutes les solutions. `node build.cjs` génère les pages modules depuis `site.js`.
