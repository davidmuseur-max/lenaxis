# LENAXIS — Site V7

Version statique du site LENAXIS préparée pour Vercel.

- Page d’accueil : composition ivoire/bleu validée
- Animation d’introduction : premières secondes de `Lenaxis FR.mp4` via Dropbox
- Capsules CORE / WATCH / AUDIT / CRISIS : extraits de `Lenaxis FR.mp4`
- Pages dédiées : `core.html`, `watch.html`, `audit.html`, `crisis.html`, `lena.html`
- Logos et captures modules : sources LENAXIS Dropbox

## Déploiement Vercel

Importer la branche `site-v7-vercel` dans Vercel. Le build installe `adm-zip`, extrait `LENAXIS_SITE_V7.zip` vers `public/`, puis Vercel sert ce dossier.
